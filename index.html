📲 Instalar MangoAR como App

Íconos PNG 192/512 + Service Worker + Manifest listos

¿Por qué antes decía "No disponible"?

Chrome y Android exigen que la app tenga íconos PNG reales (192×192 y 512×512), un manifest.json con rutas relativas y el sw.js registrado en tu dominio publicado (no dentro de una vista previa temporal).

Pasos para instalarla ahora mismo:
1. Tocá Publicar en GitHub (1 clic) para subir los nuevos íconos PNG y el Service Worker a PimpoTec/Gastando.
2. Abrí el link de tu app en Vercel o GitHub Pages en Chrome (Android/PC) o Safari (iPhone).
3. En Android/Chrome tocá el menú ⋮ → Instalar aplicación (o el botón de abajo), y en iPhone tocá Compartir ⬆️ → Agregar a inicio.
